# Hooks

A hook has one job: make the right person stop in 1–3 seconds. About half of all drop-off happens there. Write three hooks per piece, each of a different type, and use the strongest.

## Layered hook (always)
Three things say the same promise at once:
1. **First frame:** the most striking visual, already on screen before the first word. No logo, no intro, no slow zoom on nothing.
2. **On-screen text:** at most 7 words. Must work with the sound off.
3. **Spoken line:** at most 10 words, lands within 2 seconds.

## Hook types

| Type | Use when | Shape (Spanish, illustrative) |
|---|---|---|
| Pregunta real | the idea is a beginner question | "¿Por qué la IA a veces se inventa cosas?" |
| Mito | a common belief is wrong | "La IA no 'piensa'. Esto es lo que hace de verdad." |
| Noticia clara | news pillar | "Esta semana pasó algo con la IA. Versión corta:" |
| Resultado primero | practical video | "Esto me tomó 20 segundos y antes eran 20 minutos." |
| Número | a short list | "3 cosas que no debes pegar en un chat de IA." |
| Te ves a ti | identity call-out for beginners | "Si todavía no sabes qué es un prompt, esto es para ti." |
| Error común | careful pillar | "Casi todas hacen esto con la IA y es un error." |
| Traducción | jargon explainer | "'Modelo de lenguaje' en palabras normales:" |
| Contraste | before/after | "Antes: 10 mensajes. Ahora: uno." |

## Rules
- Specific beats broad: "una IA que escribe tus mensajes difíciles" beats "una herramienta increíble".
- Speak to one viewer ("tú"), written as if for one person.
- Promise only what the payoff delivers. A hook that over-promises creates a mid-video drop-off and loses reach.
- Never invent a stat, a "secret" or urgency to stop the scroll.
- No: "Hola, soy Camila", "en este video", "hoy te voy a contar", "no vas a creer", "esto es increíble".
- Vary the type across a batch; never the same type twice in a row.
- Hook is a variable, not a one-time decision: keep alternates B and C for A/B testing the same body.

## Loop
If the last line flows back into the first ("…y por eso la primera pregunta importa" → "¿Por qué la IA se inventa cosas?"), replays rise. Use it only when it feels natural.

## Tone check
Read the hook aloud. If it sounds like an ad, a headline or a tech conference, rewrite it as something she'd text a friend.

# AI Starter Trail (v4): начальный уровень 14–15, мини-игры на каждой станции

Копия движка `../ai-trail-v3/` (тот же дизайн, карта, Блуп, бой с Глитчем на Phaser) с новым курсом для новичков 14–15 лет. v3 и старые версии не тронуты.

- Курс: `https://snowflakee-e.github.io/kids-ai-courses/ai-trail-v4/`
- Для родителей: `…/ai-trail-v4/parents.html`
- Бой без прохождения: `…/ai-trail-v4/#fight`

Прогресс отдельный (`bloop-trail-v4`), Блуп-помощник общий (`../ai-trail/worker/`).

## Что изменилось по сравнению с v3

| v3 (14–17) | v4 (14–15, начальный) |
|---|---|
| 10 станций по ~22 мин | 6 станций по ~15 мин и босс |
| Чтение 3–4 мин | Чтение ~3 мин, проще слова |
| Только «учебные» задания | Мини-игра на каждой станции |
| Фейки, предвзятость, карьера, проекты | Основы: что такое ИИ, промпты, что нельзя рассказывать ИИ, честное использование |
| Цель 2 станции в неделю | Цель 3 станции, отдых после 3 |

## Мини-игры (`minigames.js`)

Новые типы заданий, добавляются в `app.tasks`. Формат данных — в шапке `course.en.js`.

| Тип | Что делает ученик | Оценка |
|---|---|---|
| `poster` | Выбирает верные факты из колоды (ловушки трясутся и объясняют, почему нет), меняет заголовок, цвета, стикер, скачивает PNG 1080×1350 | факты / (факты + ловушки) |
| `glitch` | Ищет глюки на «ИИ-картинке» (`scenes.js`): 6 пальцев, 5 лап, «13» на часах, буквы-каша, тень к солнцу | (найдено − ¼ за промах) / всего |
| `meter` | Собирает промпт из колоды: по карточке на Role / Task / Context / Format, шкала силы растёт. Мусор: личные данные, «Make it amazing!!!», «напиши всё за меня» | части / (части + мусор) |
| `draw` | Рисует по размытому промпту, потом по подробному (таймер), сравнивает и отмечает, какие детали нарисовал | без оценки |
| `redact` | Закрашивает в сообщении чатботу то, что ИИ не нужно (имя, школа, email, пароль), не трогая суть задачи | (закрыто − ½ за лишнее слово) / секреты |
| `hint` | Решает задачу-ловушку; подсказки бесплатны, «просто скажи ответ» — половина балла | решил = 1, сдался = 0.5 |

Плакаты и рисунки сохраняются в портфолио картинкой (JPEG 540 px в localStorage) и скачиваются из профиля.

Важно: в `app.js` есть глобальная константа `CSS` (строка стилей), поэтому `CSS.escape` в мини-играх не работает.

## Источники теории

Идеи взяты из открытых материалов (см. `../research/kids-ai-course-sources.md`): Code.org How AI Works, Google Prompting Guide 101 (persona, task, context, format), OpenAI и Anthropic о промптах («тест друга без контекста»), NSPCC/Vodafone («чат как разговор в людном месте»), Bitdefender/Norton (что не писать чатботу), исследование Bastani et al. (ИИ с готовыми ответами ухудшил результат теста, ИИ с подсказками — почти нет). Тексты, примеры и игры свои.

## Проверка

```
node --test tests/game.test.js
```

Тесты проверяют структуру (6–8 станций, две части, мини-игра на каждой станции, каждая мини-игра используется), данные мини-игр (зоны глюков внутри картинки и не перекрываются, в колоде промпта ровно одна карточка на часть, секреты в `redact` размечены), XP, звания, награды.

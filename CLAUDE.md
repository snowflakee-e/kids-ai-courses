# Твой человек
Студент, развиваюсь в сфере ИИ-агентов и ИИ-инфлюенсерства. Создаю автономных агентов для соцсетей: от контент-планирования и ТЗ до интеграции сервисов и генерации аватаров.

# Проекты
Развитие сети аккаунтов в Instagram/TikTok в следующих нишах:
- Аффирмации для мужчин (блог девушки, стиль: просто, понятно, действенно).
- Курсы по ИИ для детей.

# Как работаем
При использовании ключевых слов по контент-планам действую автономно, сам определяю аудиторию и оптимизирую текст.

Ключевые слова:
- `контент план`: Действую самостоятельно.
- `аффирмация`: Контент-план для блога девушки (аффирмации для мужчин).
- `курсы для детей`: Контент-план для продажи курсов по ИИ.

# Чего не делать
1. Границы: Не удалять файлы и не выходить за пределы рабочей папки без разрешения.
2. Анти-паттерны: 
- Никаких длинных вступлений и вежливости («Конечно!», «Рад помочь» и т.д.).
- Не пересказывать сделанное.
- Без избыточных объяснений очевидного и «воды».

# Частые задачи
- Составление контент-планов (табличный вид для человека + JSON для автоматизации).
- Создание ТЗ для ИИ-генераторов видео и аватаров.
- Проектирование пайплайнов интеграции между ИИ-сервисами.

# Инструменты и среда
- Оркестрация: Make.com (Core/Pro).
- Текст/Логика: Claude API (Sonnet), Claude Code.
- Видео: HeyGen API (аватары), Kling API (сцены/движение).
- Данные: Apify (Instagram Scraper) -> JSON.
- Публикация: Postiz API.
- Рабочее пространство: папка `Code`.

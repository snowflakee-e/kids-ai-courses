# Тропа ИИ — прототип курса для 14–15 лет

Лесная карта со станциями, по которой идёт Блуп. Блок = зона леса, урок = станция, задание = один экран урока. Сервер не нужен: чистые HTML/CSS/JS, прогресс хранится в `localStorage` браузера (ключ `bloop-trail-v1`).

## Запуск

Из корня репозитория (урок берёт маскота из `../bobik.js`):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/ai-trail/
```

На GitHub Pages: `https://snowflakee-e.github.io/kids-ai-courses/ai-trail/` (после мержа в ветку, с которой публикуется сайт).

Тесты логики: `node --test tests/game.test.js`.

## Что внутри урока

| Тип задания | Что делает ребёнок | Оценивается |
|---|---|---|
| `cards` | Листает карточки теории, открывает «а как думаешь?» | нет |
| `video` | Смотрит ролик; пока роликов нет — раскадровку из сцен | нет |
| `sort` | Раскладывает карточки по двум корзинам | да, долей верных |
| `build` | Собирает промпт по формуле РЗКФ | да, слоты с первой попытки |
| `spot` | Находит выдумку ИИ или лишние личные данные | да |
| `poll` | «Продолжи как нейросеть» | нет |
| `mission` | Пробует промпт в настоящем чат-боте | нет |
| `quiz` | Вопрос теста | да |

Звёзды: 3 — без ошибок, 2 — от 75%, 1 — от 50%. Меньше 50% — станция не пройдена, следующая не откроется. Повтор даёт только разницу XP с лучшим результатом. Правила XP, уровни и награды — в конце `course.js`.

## Файлы

```
course.js         контент: блоки, уроки, задания, сцены роликов, XP, уровни, награды
game.js           логика без интерфейса: открытие станций, звёзды, XP, серии
app.js            интерфейс: карта, урок, итоги, звуки, конфетти
style.css         стили, светлая тема «день» и тёмная «ночной лес»
tools/video-tz.js сборка VIDEO_TZ.md и JSON сцен для автоматизации
VIDEO_TZ.md       ТЗ на ролики
```

## Для тестирования с детьми

- ⚙️ → «Режим автора» открывает все станции.
- ⚙️ → «Сбросить прогресс» — начать заново в этом браузере.
- Урок можно закрыть на любом задании: при следующем входе продолжится с того же места.

Чтобы видеть результаты детей, создай в Make.com сценарий Custom Webhook → Google Sheets и вставь адрес в `CONFIG.resultsWebhook` в `app.js`. После каждого урока придёт форма с полями `name, course, block, lesson, lessonTitle, stars, scorePct, xpEarned, xpTotal, level, plays, durationSec, scores, finishedAt`.

## Ограничения прототипа

- Прогресс живёт в одном браузере на одном устройстве.
- Нет входа и закрытого доступа: для платного курса нужен бэкенд (Supabase или Firebase), логику из `game.js` можно перенести как есть.
- Блоки 2 и 3 на карте — заглушки «скоро».

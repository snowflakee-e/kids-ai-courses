# Блуп-помощник (Cloudflare Worker)

Сервер-посредник между курсом и бесплатной нейросетью Cloudflare Workers AI. Нужен, потому что сайт на GitHub Pages статический: ключ или доступ к модели нельзя держать в коде страницы.

- Модель: `@cf/google/gemma-4-26b-a4b-it`, запасная `@cf/meta/llama-3.3-70b-instruct-fp8-fast` (если первая не ответила).
- Ключей API нет: модель подключается привязкой `AI` в настройках воркера.
- Помощник говорит только о текущем задании и темах курса, просит не писать личные данные.
- Переписка нигде не сохраняется.

## Что делает

Курс шлёт `POST` с JSON:

```json
{
  "lang": "ru",
  "mode": "check",
  "lesson": "Что такое ИИ",
  "context": { "question": "Как ИИ учится?", "points": ["много примеров", "поправки после ошибок"] },
  "messages": [{ "role": "user", "content": "Ему показывают много картинок" }]
}
```

- `mode: "check"` — задание «Объясни Блупу»: модель оценивает ответ по пунктам `points` и подсказывает, чего не хватает. В ответе есть `verdict`: `yes`, `partly` или `no`.
- `mode: "mistake"` — кнопка «Спросить Блупа» после ошибки: в `context` лежат `question`, `answer`, `correct`, `explain`.

Ответ: `{ "reply": "текст", "verdict": "partly" }`. Ошибки: `400` неверные данные, `403` чужой сайт, `429` слишком часто, `502` модель не ответила, `503` закончился дневной лимит.

## Как запустить

### Через сайт Cloudflare

1. **Workers & Pages → Create → Worker**, имя `bloop-tutor`, создать из шаблона «Hello World» и нажать **Deploy**.
2. **Edit code**: заменить весь код на содержимое `src/index.js` и снова нажать **Deploy**.
3. **Settings → Bindings → Add → Workers AI**, имя переменной `AI`. Сохранить.
4. Скопировать адрес воркера, вида `https://bloop-tutor.<твоё-имя>.workers.dev`.

### Через консоль

```bash
cd ai-trail/worker
npx wrangler login
npx wrangler deploy
```

`wrangler.toml` уже содержит привязку `AI` и список разрешённых сайтов.

## Проверка

```bash
curl -X POST https://bloop-tutor.<твоё-имя>.workers.dev \
  -H "Origin: https://snowflakee-e.github.io" \
  -H "Content-Type: application/json" \
  -d '{"lang":"ru","mode":"check","lesson":"Что такое ИИ","context":{"question":"Как ИИ учится?","points":["много примеров"]},"messages":[{"role":"user","content":"Ему показывают много примеров"}]}'
```

Должен прийти JSON с `reply`. Если пришло `{"error":"origin"}` — не передан заголовок `Origin`.

## Подключение к курсу

Вставь адрес воркера в `CONFIG.tutorUrl` в `ai-trail/app.js`. Пока адрес пустой, помощник выключен: кнопки «Спросить Блупа» нет, а «Объясни Блупу» работает как самопроверка с примером ответа.

## Настройки (Settings → Variables)

| Переменная | Зачем |
|---|---|
| `ALLOWED_ORIGINS` | Сайты, которым можно обращаться к помощнику, через запятую. По умолчанию GitHub Pages курса и `localhost:8000`. |
| `MODEL` | Другая основная модель, например `@cf/meta/llama-3.3-70b-instruct-fp8-fast`, если Gemma слабо отвечает по-русски. |
| `MODEL_FALLBACK` | Другая запасная модель. |

## Лимиты

- Бесплатно 10 000 «нейронов» в день на аккаунт. Одно сообщение помощнику на Gemma 4 — около 20 нейронов, то есть несколько сотен сообщений в день. Llama 3.3 70B примерно в 5 раз дороже.
- На бесплатном тарифе Workers при исчерпании лимита помощник просто молчит до следующего дня, курс показывает «Блуп устал на сегодня». На платном тарифе Workers сверх лимита списываются деньги: $0,011 за 1000 нейронов.
- Ограничение частоты по IP — блок `[[ratelimits]]` в `wrangler.toml`, по умолчанию закомментирован.

## Тесты

```bash
cd ai-trail/worker
node --test
```

Workers AI в тестах подменяется заглушкой, проверяются CORS, проверка входных данных, промпт, разбор оценки, запасная модель и дневной лимит.

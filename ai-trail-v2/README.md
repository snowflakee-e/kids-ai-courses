# AI Trail v2 — эксперимент с дизайном для 14–17 лет

Копия курса `../ai-trail/` с новым дизайном. Уроки те же, меняется то, как курс выглядит и звучит. Оригинал не тронут: можно открыть обе версии и сравнить.

- Новая версия: `https://snowflakee-e.github.io/kids-ai-courses/ai-trail-v2/`
- Страница для родителей: `…/ai-trail-v2/parents.html`
- Старая версия: `https://snowflakee-e.github.io/kids-ai-courses/ai-trail/`

Прогресс у версий раздельный (`bloop-trail-v2` и `bloop-trail-en-v1`), Блуп-помощник общий (`../ai-trail/worker/`).

## Что изменилось и почему

| Было | Стало | Зачем |
|---|---|---|
| Сказочный лес: деревья со стволами, грибы, цветы, светлячки, деревянные таблички | Карта как в игре: сетка, изолинии рельефа, редкие значки, тёмные заголовки зон «Zone 01» | Подростки отталкивают всё «для малышей» (исследование, стр. 19–22) |
| Блуп в центре: большой робот в карточках, итогах, шапке | Блуп — стикер в углу карточки и подсказки, в шапке — логотип | Для 14–17 маскот — реакция-стикер, не главный герой |
| Ответ ИИ в пузыре, как в мессенджере для детей | Ответ ИИ текстом с аватаром, поле ввода как в приложениях ИИ | Похоже на настоящие инструменты |
| Nunito и Rubik с Google Fonts, пастель | Space Grotesk + Inter из папки `fonts/`, один акцент — лайм, высокий контраст | Взрослее, и шрифты не отправляют IP посетителя в Google (GDPR) |
| Эмодзи в кнопках | Линейные иконки | Аккуратнее, одинаково на всех устройствах |
| Конфетти после каждого урока | Конфетти: зона пройдена, первый идеальный урок, победа над боссом | Частая награда перестаёт что-то значить |
| Trail Rookie → AI Master | Intern → Trainee → … → Prompt Engineer → … → AI Architect | Звания со смыслом |
| — | Профиль: навыки по зонам, портфолио, награды, сертификат | Награды с реальной ценностью |
| — | Карточка «мои навыки» 1080×1920 для сторис: звание, звёзды, навыки. Имя — только если включить | Её не стыдно выложить, это и реклама курса |
| «Hi, I’m Bloop!», «Big brain move!» | «Hey, Emma.», «Nailed it.», «Not quite.» | Тон старшего брата или сестры |
| Цены в $ в примерах | Без валюты | Курс для Европы и США |
| — | Настройки вида: тема (как в телефоне / светлая / тёмная), крупный текст, шрифт для лёгкого чтения (Atkinson Hyperlegible), меньше движения | Доступность |
| — | Субтитры: поле `captions` (.vtt) у ролика, у YouTube субтитры включены по умолчанию | Подростки часто смотрят без звука |
| — | `parents.html`: что учат, как защищён Блуп, что с данными, что может родитель | Покупает родитель: ему нужна спокойная страница без игры |

Орфография — американская по всему курсу (color, favorite, math, Mom, 9th grade). Так было и раньше.

## Профиль

Кнопка с человечком в шапке.

- **Skills** — навыки каждой зоны (`skills` у блока в `course.en.js`), пройденные отмечены.
- **Portfolio** — ответы из письменных заданий с `portfolio: true`: промпты, планы, питч проекта. Хранится последний ответ на задание. Есть кнопка «Copy».
- **Badges** — награды (раньше были в настройках).
- **Certificate** — открывается после победы над боссом. Имя вводится отдельно (можно полное), печать или сохранение в PDF через браузер. Внизу честно: «Not an accredited qualification».
- **Share my skills card** — картинка рисуется в браузере. На телефоне открывается меню «Поделиться», на компьютере картинка скачивается.

## Файлы

```
index.html     страница курса: шапка с иконками, профиль, карточка, настройки вида, блок сертификата для печати
style.css      дизайн-система v2: токены светлой и тёмной темы, карта, урок, профиль, печать, страница родителей
app.js         логика интерфейса: значки карты, стикер-Блуп, голос интерфейса, профиль, сертификат, карточка, настройки вида
game.js        логика курса (как в ai-trail) + поля portfolio и настроек вида
course.en.js   уроки (как в ai-trail) + звания, skills у зон, portfolio у письменных заданий, нейтральные цены
parents.html   страница для родителей
fonts/         Space Grotesk, Inter, Atkinson Hyperlegible (лицензия OFL — fonts/LICENSE-OFL.txt)
tests/         тесты логики и данных: node --test tests/game.test.js
```

ТЗ на ролики собирается из `../ai-trail/course.en.js` (`../ai-trail/tools/video-tz.js`): сцены роликов в версиях одинаковые.

## Как проверить на подростках

Тот самый тест из исследования (план на 90 дней, недели 1–2).

1. Найди 5–6 подростков 14–15 лет (с согласия родителей).
2. Покажи старую версию и v2 в разном порядке: половине сначала старую, половине — новую.
3. Первый вопрос, до того как они что-то нажмут: «Для кого это приложение?» Если отвечают «для младших» — версия провалена.
4. Дай пройти одну станцию в каждой. Спроси: что понравилось, что раздражало, что выложил бы в сторис.
5. Не подсказывай. Записывай, где застревают.

Если v2 выигрывает: перенеси файлы v2 в `../ai-trail/` (кроме `README.md` и `tests/`, их объединить), удали `ai-trail-v2/`, поменяй `storageKey` обратно на `bloop-trail-en-v1`, чтобы прогресс учеников сохранился.

## Ограничения

- Прогресс, портфолио и настройки живут в одном браузере.
- Лимит родителя можно обойти, очистив данные сайта (вместе с прогрессом). Надёжно — только с аккаунтами.
- Сертификат подтверждает прохождение только в этом браузере, проверить его снаружи нельзя.
- Если включить `CONFIG.resultsWebhook` в `app.js`, поправь раздел о данных в `parents.html`.

# AI Trail v3 — меньше станций, больше содержания, без роликов

Копия `../ai-trail-v2/` (тот же дизайн для 14–17 лет) с другой структурой курса. v2 и оригинал `../ai-trail/` не тронуты: можно открыть все версии и сравнить.

- Новая версия: `https://snowflakee-e.github.io/kids-ai-courses/ai-trail-v3/`
- Страница для родителей: `…/ai-trail-v3/parents.html`

Прогресс отдельный (`bloop-trail-v3`), Блуп-помощник общий (`../ai-trail/worker/`).

## Что изменилось

| v2 | v3 | Зачем |
|---|---|---|
| 21 станция: 14 уроков по 6–10 мин, 3 ответвления, 3 теста зон, босс | 10 станций: 9 по ~22 мин и босс | Меньше точек на карте, каждая станция — законченная тема |
| Теория — 2–3 карточки и ролик (раскадровка) | Теория — длинное чтение (`read`) на 3–4 минуты: разделы, примеры промптов в виде чата, «Check yourself», «Pro tip», итоги | Роликов нет и не нужно их делать; информации в 2–3 раза больше |
| Ответвления (x1–x3) и тесты зон (t1–t3) | Вошли в основные станции: «Teach it back» — в s3, «Research like a pro» — в s5, «Study bot» — в s6; вопросы тестов — в квизы станций | Ничего не потеряно, просто меньше станций |
| Урок: предсказание → карточки → практика | Станция из двух частей: предсказание → чтение → практика, и так дважды | Длинная станция не утомляет: внутри два коротких круга |
| Цель недели 3 станции, отдых после 3 | Цель 2 станции, отдых после 2, лимит родителя 1–3 | Станция теперь в 2–3 раза длиннее |
| Звания до 2500 XP | Звания до 1500 XP (максимум ~2200) | Меньше станций — меньше бонусов за урок |

Станцию можно бросить на любом задании и продолжить потом (так было и раньше), поэтому 22 минуты не обязательно проходить за раз.

## Тип задания `read`

```js
{ type: 'read', part: 1, title: '…', minutes: 4, pose: 'point',
  intro: '…',
  sections: [{ h, text, big, list, example: { me, ai }, after, tip, check: { q, a } }],
  takeaways: ['…'] }
```

`**слово**` в тексте — выделение. Правило: текст учит, задание проверяет. В чтении нет готового ответа на сортировку, «найди ошибку» или «расставь по порядку» той же станции — тесты это не ловят, следи сам при правках.

## Босс — игра на Phaser

Финальная станция `boss` — настоящий бой, а не вопросы с полоской HP: интро-карточки → `arena` → «Final strike» (`talk`).

- Управление: WASD или стрелки — ходить, мышь — целиться, клик или пробел — стрелять, Esc — пауза. На телефоне (лёжа): левый палец — движение, правый — стрельба туда, где касаешься.
- Раунды — только про ИИ и как им пользоваться: как устроен чатбот, «гладко ≠ верно», контекст, промпт, уточнения, галлюцинации, ИИ как репетитор, источники, промпт для картинки, предвзятость.
- Раунд = вопрос из курса (`rounds` в `course.en.js`: `topic`, `q`, `options` — первый верный, до 70 знаков, `explain`). Варианты летают карточками, 3 попадания — выбор. Верный снимает щит, Глитча можно бить несколько секунд. Неверный взрывается пулями.
- Здоровье Глитча режется по раундам: пока есть вопросы, его не добить, все 10 раундов обязательны. После последнего — финальная фаза без щита.
- Оценка: доля раундов с ответом с первой попытки, минимум 0.5 за победу (1 звезда), от 75% — 2 звезды, все 10 — 3. За победу — бонус `bossDone` (200 XP), один раз. Смерти не штрафуются: Блуп возвращается в тот же раунд. В XP и комбо бой считается как 10 заданий (`weightOf` в `game.js`).
- После взрыва Глитча — экран победы в игре (звёзды, с первой попытки, время, нокауты, «Continue»).
- После боя — разбор всех раундов с объяснениями. Кнопка «Answer without shooting» — те же раунды обычными вопросами (нет клавиатуры, не хочется стрелять); оценка та же.
- «Less motion» в настройках: без тряски, вспышек и дрожания, пули реже.
- Phaser 3.90 лежит в `vendor/phaser.min.js` (~1.2 МБ, лицензия MIT рядом) и грузится только при старте боя, без CDN.
- Финал курса (`#finale`): после победы кнопка «Finish the trail →» и кнопка «Trail complete» на карте. Итоги, навыки по зонам, правила ученика из «Final strike» (сохраняется в портфолио), что делать дальше, сертификат и карточка.
- Посмотреть бой без прохождения станций: `…/ai-trail-v3/#fight`. Это просмотр: прогресс, звёзды и XP не меняются.

## Деплой

GitHub Pages кэширует файлы на 10 минут. В `index.html` у CSS и скриптов есть `?v=…`: **меняй это число при каждом деплое**, иначе у учеников может остаться старый код.

`arena.js` — бой (сцена Phaser, текстуры рисуются кодом, Блуп — из `../bobik.js`), `vendor/` — Phaser.

Как в v2. Отличия: в `app.js` вместо плеера роликов — `read`, в листе станции — оглавление частей; в `style.css` стили чтения вместо плеера; `course.en.js` переписан; `tests/game.test.js` — проверки под 10 станций (две части, ≥6 заданий практики, без роликов, без ответвлений).

## Как проверить на подростках

Как в README v2, но сравнивать v2 и v3: дай пройти одну станцию в каждой. Спроси: что было интереснее, где стало скучно, дочитали ли текст до итогов, хотят ли ролики обратно. Смотри, где закрывают урок.

Если v3 выигрывает: перенеси файлы v3 в `../ai-trail/`, обнови курс в `../catalog.js` (`lessons: 10`, `minutes: 22`), поменяй `storageKey`. Старый прогресс к новым станциям не подходит (другие id), ученики начнут заново.
